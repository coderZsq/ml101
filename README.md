# ML101 · 交互式机器学习入门

ML101 是一门在浏览器中学习机器学习的入门课程。从数字、图像和变化率开始，通过交互实验和小测，逐步理解模型如何预测、衡量误差和学习分类。

## 运行

需要 Node.js 和 npm。在项目目录运行：

```bash
npm install
npm run dev
```

按照终端提示打开页面。`npm run build` 生成生产构建，`npm run preview` 预览构建结果。课程进度保存在当前浏览器的本地存储中。

## 当前课程

当前包含开篇和 44 个小节，按顺序覆盖：

1. **数、图像与变化**：输入输出、坐标、变化率、导数和下坡方向。
2. **预测与训练**：模型参数、误差、损失、梯度、训练循环和线性模型。
3. **泛化与分类**：训练、验证和测试，过拟合、数据泄漏、分类指标、距离和最近邻。
4. **神经元基础**：加权求和、判断门槛和分类边界。

每节通过动手观察和小测学习；具体内容以网页课程为准。课程是学习机器学习的起点，完成课程本身不等于掌握完整的深度学习或研究能力。

## 学习路线

完成网页课程后，可以继续补充线性代数、微积分和概率统计，再通过实现小型模型理解前向计算和反向传播。之后可系统学习深度学习、Transformer 和模型评估，尝试阅读论文、复现小规模实验并记录结果。更深入的方向包括语言模型、视觉、多模态和机器学习系统；这些是后续学习方向，并非当前网页已经提供的课程。

学习时建议先描述输入、输出与假设，再动手实验：一次改变一个变量，对比训练集和未参与训练的数据，并解释结果是否支持原先的判断。使用 AI 辅助实现时，仍需自行审查数据划分、评价指标和实验结论。

## 项目结构

```text
index.html       页面入口
css/style.css    界面样式
js/main.js       课程导航、进度和测验
js/lessons.js    课程内容和交互实验
package.json     开发与构建命令
```

网页使用原生 JavaScript、ES Modules 和 Canvas，Vite 用于开发与构建。

## 界面与图表约定

新增或修改图表时，主曲线和主要图形默认使用白色，坐标轴与辅助线使用中性灰。需要区分数据系列或突出交互点时可以使用其他颜色，文字说明应与图表保持一致。
